Purrphect monorepo: Expo SDK 58 apps (expo-router, NativeWind 4, React Native Reusables, expo-sqlite) with Next.js static sites, pnpm workspaces + Turbo.

Expo changes every SDK. Before touching an Expo or React Native API, read the versioned docs at
https://docs.expo.dev/versions/v58.0.0/ instead of trusting memory.

## Commands

```bash
pnpm typecheck                     # turbo, every package
pnpm check                         # biome, whole repo
pnpm test                          # turbo: vitest + jest
pnpm verify                        # everything the CI workflow runs, in order
pnpm verify:e2e [ios|android]      # verify, then Maestro on a fresh simulator/emulator; both by default
pnpm ios / pnpm android            # dev build of dart; Expo Go is not supported
pnpm release [patch|minor|major]   # opens the auto-merging version bump PR
pnpm op <cmd> / pnpm op-prod <cmd> # run with 1Password dev / prod environment
```

Add native dependencies from the app folder with `pnpm expo install <package>`. Shared versions live in the
`catalog` in `pnpm-workspace.yaml`; `pnpm lint:ws` (sherif) keeps them consistent.

## Layout

- `apps/<name>`: one Expo app per folder, `apps/<name>-web` its Next.js static site. `src/app` holds routes only.
- `apps/dart/src/game`: plain TypeScript, no React or native imports. A match is a list of darts; `replay` derives everything else.
- `packages/ui` (`@purrphect/ui`): shared components, theme tokens, Tailwind preset. Import by file, e.g. `@purrphect/ui/button`; there is no index.
- `tooling/github`: composite actions for CI; `tooling/e2e`: device and build scripts shared by those actions and `pnpm verify:e2e`; `tooling/store-assets`: store screenshot rigs and the app icon generator (`pnpm --filter @purrphect/store-assets icon`); `tooling/fastlane`: pinned fastlane for store uploads.
- `ios/` and `android/` are generated by prebuild. Never edit them by hand; configure through `app.json`.
