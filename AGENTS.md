Dart Purrphect: Expo SDK 58 app (expo-router, NativeWind 4, React Native Reusables, expo-sqlite).

Expo changes every SDK. Before touching an Expo or React Native API, read the versioned docs at
https://docs.expo.dev/versions/v58.0.0/ instead of trusting memory.

## Commands

```bash
pnpm expo install <package>  # native deps, resolves SDK-compatible versions
pnpm typecheck
pnpm lint                    # biome check
pnpm test                    # vitest, game logic in src/game
pnpm ios / pnpm android      # dev build, Expo Go is not supported
```

## Layout

- `src/app` routes only. Components, hooks and logic live outside it.
- `src/game` is plain TypeScript with no React or native imports. A match is a list of darts; `replay` derives everything else.
- `ios/` and `android/` are generated by prebuild. Never edit them by hand; configure through `app.json`.
